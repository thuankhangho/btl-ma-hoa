      Khóa bí mật được sinh và lưu trên máy chủ. Trình duyệt chỉ nhận khóa công khai, dấu vân tay và file đã ký. Định dạng khối chữ ký giống hệt bản JavaScript, nên file ký bằng bản web JS cũng xác minh được ở đây.

      Các module mật mã tự cài đặt theo chuẩn nào?
      ModuleNội dungChuẩn
      sha256.pyĐệm, lịch thông điệp W₀…W₆₃, 64 vòng nén với Σ0, Σ1, Ch, MajFIPS 180-4
      hmac.pyH((K ⊕ opad) ‖ H((K ⊕ ipad) ‖ m)), dùng để sinh k cho DSARFC 2104
      numtheory.pyBình phương và nhân, Euclid mở rộng, nghịch đảo mô-đun, Miller-Rabin, sinh số nguyên tố, căn nguyên thủyFIPS 186-4 C.3
      rsa.pySinh khóa (λ(n), CRT), RSASP1/RSAVP1, MGF1, EMSA-PSS encode/verifyRFC 8017
      elgamal.pyr = αᵏ, s = k⁻¹(m − a·r) mod (p−1); xác minh βʳrˢ ≡ αᵐ trên nhóm 2048 bitElGamal 1985, RFC 3526
      dsa.pySinh tham số (p, q, g), r = (gᵏ mod p) mod q, s = k⁻¹(H + x·r) mod qFIPS 186-4
      rfc6979.pySinh k tất định cho DSA từ (x, H(m)) bằng HMAC-DRBGRFC 6979
      der.pyTLV, OID, SubjectPublicKeyInfo cho RSA, DSA, ElGamal; PEMX.690, RFC 5280/3279

      Độ đúng được kiểm chứng trong tests/: so SHA-256 và HMAC với hashlib/hmac, chạy test vector RFC 6979, và cho thư viện cryptography xác minh chữ ký do code tự viết tạo ra (và ngược lại). Các thư viện chuẩn chỉ dùng trong test để đối chiếu. Lý thuyết chi tiết nằm trong docs/THIET-KE.md.
